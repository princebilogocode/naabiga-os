# Cahier des charges – Naabiga OS (NOS)

**Projet :** Naabiga OS (NOS)  
**Entreprise :** ICONEDOR – Burkina Faso

---

# 1. Vision

Naabiga OS (NOS) est une distribution Linux professionnelle destinée aux développeurs.

Objectif :

> Installer le système et être prêt à développer en moins de 5 minutes.

NOS est le premier système d'exploitation conçu par des Burkinabè, pour les Burkinabè et pour l'Afrique. Il s'appuie sur un **socle Linux LTS** afin de bénéficier d'une stabilité éprouvée tout en apportant une expérience entièrement pensée ici.

# 7. Applications exclusives

## NOS Center

Gestionnaire graphique permettant :

- Installer des outils
- Gérer les versions
- Installer Flutter
- Installer Android Studio
- Installer Docker

## NOS Doctor

Commande :

```bash
nos doctor
```

Vérifie :

- Flutter
- Android SDK
- Java
- Docker
- Git
- Node
- Python
- PATH
- Variables d'environnement

## NOS CLI

Commandes :

```bash
nos doctor
nos install
nos update
nos repair
nos sdk
nos doctor flutter
```

## NOS Dev Center

Interface graphique affichant l'état de tous les SDK.

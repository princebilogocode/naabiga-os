# Code de conduite

## Notre engagement

Naabiga OS est un projet porté par ICONEDOR et construit avec des étudiants. Nous voulons un espace d'apprentissage et de collaboration ouvert, respectueux et bienveillant pour toute personne, quels que soient son niveau, son âge, son genre, son origine, sa langue ou son handicap.

## Comportements attendus

- Faire preuve de respect et de patience, en particulier envers les débutants.
- Accueillir les critiques constructives et les formuler avec tact.
- Expliquer plutôt que juger : une revue de code est une occasion d'apprendre.
- Privilégier l'intérêt du projet et de la communauté.

## Comportements inacceptables

- Harcèlement, insultes, remarques discriminatoires.
- Publication d'informations privées sans consentement.
- Sabotage, plagiat, ou contournement délibéré des règles de revue.

## Application

Les mainteneurs peuvent supprimer ou refuser tout contenu contraire à ce code et exclure temporairement ou définitivement un contributeur.

Signalement : contact@iconedor.com (confidentiel).

Ce code est adapté du [Contributor Covenant](https://www.contributor-covenant.org/) v2.1.
